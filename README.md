# Will Mather

Senior Director, Analytics & AI. I help teams go from a new AI tool to daily, measured use. After hours I run my own businesses on a fleet of AI agents, and this is where the reusable parts live.

**Day job.** I lead analytics and AI enablement at a global marketing agency. I manage three direct reports inside a roughly 20-person analytics function. I took the company to 95%+ AI adoption (about 90% active weekly), trained 200+ employees and clients, and deployed 200+ production agents that cut recurring manual processing by 75%. Before that: analytics roles at agencies and in CPG data, starting in 2017.

**After hours.** About two dozen Grok Bot seats with one job each, plus Cursor cloud agents and Claude Code or Codex for code. One lead seat runs the review gate. Researchers bring a source for every number. Builders open small pull requests from a prompt file. Nothing merges until I approve that pull request at that commit. The operating model is written up in [agent-ops-showcase](https://github.com/willmather95/agent-ops-showcase).

## How I work

- Every number has a source and a date, or it doesn't ship.
- One change at a time, measured, with a receipt from production.
- Agents get one job and a written list of what they may not do.
- Checks go in code wherever code can run them.
